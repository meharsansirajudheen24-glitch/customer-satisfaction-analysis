# customer-satisfaction-analysis
Power BI dashboard analyzing customer satisfaction, ratings, service experience, and key performance indicators to identify areas for business improvement.
Customer Complaints Analysis Dashboard

📊 Project Overview

This Power BI project analyzes customer complaints to understand complaint patterns, resolution performance, customer satisfaction, and complaint trends over time.

The interactive dashboard allows users to explore complaints by complaint type and communication channel.

🛠️ Tools & Technologies

* Power BI
* Power Query
* DAX
* Data Cleaning
* Data Visualization

📈 Key KPIs

* Total Complaints: 1,200
* Resolved Complaints: 783
* Pending Complaints: 176
* In Progress Complaints: 241
* Average Resolution Time: 27.70 hours
* Average Customer Rating: 3.2

🔍 Dashboard Analysis

The dashboard includes:

* Average Resolution Time by Complaint Type
* Complaints by Complaint Type
* Complaints by Channel
* Monthly Complaint Trends
* Customer Rating by Complaint Type
* Interactive filters for Channel and Complaint Type

💡 Key Insights

* Fraud Investigation complaints have the highest average resolution time at approximately 60 hours.
* Transaction-related complaints have the highest customer rating among the complaint categories shown.
* Fraud Investigation has the lowest customer rating, indicating a potential area for service improvement.
* Complaint volumes fluctuate throughout the year, with notable peaks in March, August, and December.
* The dashboard shows that a significant number of complaints remain pending or in progress, highlighting the importance of improving resolution efficiency.

🎯 Business Objective

The objective of this analysis is to identify complaint patterns and service issues, monitor resolution performance, and provide actionable insights that can help improve customer satisfaction and complaint-handling efficiency.
